# ADR-0001: ハードウェアモデルに直接型 LFSR を採用する

- 状態: 採用
- 日付: 2026-10-09

## 文脈

初期の構想では、入力の末尾に width 個の 0 を付け足し（augmentation）、入力ビットをレジスタの LSB 側から押し込む方式で LFSR を描く予定だった。多項式の筆算と対応しやすい方式である。

その後、CRC 設定を Rocksoft モデル（init / refin / refout / xorout）全体で切り替えられるようにすることになった。

## 決定

入力ビットを MSB の出口で XOR し、その結果をフィードバックにする直接型 LFSR を採用する。0 埋めはしない。

## 理由

- Rocksoft モデルの `init` は直接型の初期レジスタ値として定義されている。0 埋め方式で同じ CRC を得るには `init` を別の値に変換する必要があり、画面に出す初期値がプリセットの `init` と一致しなくなる。
- reveng カタログの `check` 値で、表示中の計算をそのまま検証できる。
- 0 埋め方式では最初の width クロックで必ず MSB が 0 になり、序盤のスロー再生でフィードバックが一度も発火しない。直接型なら最初のクロックから `fb = 1` が起こりうる。

## 採らなかった案

- 0 埋め方式を併記する切り替え: `init ≠ 0` のときに表示値の変換を説明する画面が別途要り、教材の焦点がぼやける。
