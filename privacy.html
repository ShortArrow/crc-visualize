Privacy

crc.shortarrow.jp is measured with Cloudflare Web Analytics. Cloudflare adds a script (static.cloudflareinsights.com/beacon.min.js) to each page it serves, and the script sends Cloudflare page views and page load performance, read through the browser's Performance API.

Cloudflare's documentation states that Web Analytics does not collect or use visitors' personal data (About), that its beacon uses no client-side state such as cookies or localStorage to collect usage metrics and that its Core Web Vitals report (Vitals Explorer) does not fingerprint individuals by IP address or User Agent (Core Web Vitals), and that Cloudflare does not track individual end users across its customers' sites (Data origin and collection).

The settings you enter are kept in the browser's localStorage and in the URL query. The app sends them nowhere itself, but the URL, query included, reaches Cloudflare when the page is requested.

個人情報の扱い

crc.shortarrow.jp は Cloudflare Web Analytics で計測している。Cloudflare が配信するページにスクリプト（static.cloudflareinsights.com/beacon.min.js）を差し込み、そのスクリプトがブラウザの Performance API で読んだページの表示と読み込みの速さを Cloudflare に送る。

Cloudflare の文書は、Web Analytics は訪問者の個人データを集めも使いもしないこと（About）、計測に Cookie や localStorage のようなブラウザ側の状態を使わず、Core Web Vitals の画面（Vitals Explorer）は IP アドレスや User Agent で個人を識別（フィンガープリント）しないこと（Core Web Vitals）、顧客のサイトをまたいで個々の利用者を追跡しないこと（Data origin and collection）を説明している。

入力した設定は、ブラウザの localStorage と URL のクエリに保つ。アプリ自身はそれをどこにも送らないが、ページを読み込むとき、クエリを含む URL は Cloudflare に届く。
